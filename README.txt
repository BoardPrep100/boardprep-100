BOARDPREP 100 — VERSION 2.0

Included:
- Dashboard with syllabus completion and subject progress
- Chapter-wise syllabus tracker for five subjects
- Daily planner and task checklist
- Focus timer and study-time total
- Test score tracker
- Mistake book
- Date-based study calendar
- JSON export/import backup
- Responsive dark interface and PWA files

HOW TO TEST ON WINDOWS:
1. Extract the ZIP.
2. Open the BoardPrep100 folder.
3. Double-click index.html.
4. Try ticking a syllabus item, adding a planner task, recording a test, and refreshing the page.

IMPORTANT:
- Data is stored in this browser using LocalStorage. It does not sync automatically between PC and iPhone yet.
- PWA install/offline features require HTTPS hosting or localhost.
- iPhone: open the HTTPS site in Safari > Share > Add to Home Screen.
- Windows: open the HTTPS site in Edge/Chrome > Install app (if offered).
- Cloud login and sync need a Supabase project, its URL and publishable key, plus database policies. Do not share secret/service-role keys.
- CBSE reference: https://cbseacademic.nic.in/curriculum_2027.html
- The Hindi A chapter entries are deliberately broad because the official curriculum PDF's detailed prescribed-text list needs confirmation against the latest school/textbook list. Use the tracker to add/rename chapters as required.
